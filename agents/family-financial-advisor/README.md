# family-financial-advisor

가족 재무 상담 전문가. 소득/지출/자산 분석과 맞춤 재무 계획 수립. 재무 상담, 가계부 분석, 절세, 투자 전략, 보험 리뷰 요청 시 위임.

## 주요 기능

- 소득, 지출, 자산 종합 분석
- 가계부 분석 및 재무 현황 진단
- 맞춤형 재무 계획 수립
- 절세 전략 제시
- 투자 전략 상담
- 보험 포트폴리오 리뷰 및 최적화

## 사용 방법

- 에이전트는 Task 도구를 통해 자동으로 위임됩니다
- 트리거: 재무 상담, 가계부 분석, 절세, 투자 전략, 보험 리뷰 등
