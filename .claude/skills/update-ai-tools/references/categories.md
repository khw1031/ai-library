# 스킬 카테고리 분류 가이드

skills/README.md 작성 시 아래 카테고리로 스킬을 그룹화합니다.

## 카테고리 목록

| 카테고리 | 설명 | 해당 스킬 패턴 |
|----------|------|---------------|
| 생성 도구 | Skill, Agent 등 AI 자산 생성 | `create-*`, `*-ai-tool` |
| 워크플로우 | 단계별 작업 진행 | `*-workflow` |
| 코드 품질 | 코드 리뷰, 분석, 설명 | `code-review-*`, `kind-senior-*` |
| 규칙 관리 | 프로젝트 규칙 생성/추가/구조화 | `add-rules`, `*-rule-*`, `rule-*` |
| 디자인 시스템 | Figma 디자인 규칙 추출 | `*-design-rule-*`, `figma-*` |
| Git & 배포 | 커밋, 변경 이력, 패키지 배포 | `git-*`, `changelog`, `package-*` |
| 문서 관리 | 문서 통합, 스킬 인덱싱, 도구 갱신 | `document-*`, `skills-ref`, `update-*` |
| 프롬프트 & 원칙 | 프롬프트 개선, 설계 원칙 | `prompt-*`, `progressive-*` |
| 실행 전략 | 작업 분해, 병렬 처리 | `parallel-*` |

## 분류 규칙

1. **패턴 매칭 우선**: 스킬 이름이 위 패턴과 일치하면 해당 카테고리
2. **description 기반**: 패턴 불일치 시 description 키워드로 판단
3. **새 카테고리**: 기존 카테고리에 맞지 않으면 새 카테고리 생성 가능
4. **복수 해당**: 여러 카테고리에 해당하면 주요 기능 기준으로 1개 선택
