# financial-budget-management

가계 예산 수립, 지출 관리, 저축 전략을 안내합니다.

## 주요 기능

- 가계 예산 수립 및 관리
- 월별/항목별 지출 관리 전략
- 저축 목표 설정 및 달성 방법
- 비상자금 조성 계획
- 소비습관 분석 및 개선안 제시
- 지출분석 및 재무목표 수립

## 사용 방법

- 에이전트 전용 스킬 (자동 위임)
- 트리거: 예산, 가계부, 지출관리, 저축, 비상자금, 절약, 소비습관, 지출분석, 재무목표
