## 예산 수립 프레임워크 상세

### 50/30/20 룰 실전 적용

**수입 산정 기준: 세후(실수령액) 기준**

```
월 실수령액 = 총급여 - 소득세 - 4대보험 - 기타공제
```

**카테고리별 상세 항목:**

#### 필수 지출 (50%) - Needs

| 항목 | 포함 내용 | 적정 비율 |
|------|----------|----------|
| 주거비 | 월세/대출이자/관리비 | 소득의 25% 이내 |
| 식비 | 장보기, 기본 외식 | 소득의 10~15% |
| 교통비 | 대중교통, 자동차유지비, 주유비 | 소득의 5~7% |
| 통신비 | 핸드폰, 인터넷, TV | 소득의 2~3% |
| 보험료 | 건강보험, 자동차보험, 실손보험 | 소득의 5~7% |
| 최소 부채상환 | 대출 최소 상환액 | 가능한 낮게 유지 |
| 필수 의료비 | 정기 검진, 만성질환 치료 | 변동 |

#### 선택 지출 (30%) - Wants

| 항목 | 포함 내용 | 절감 포인트 |
|------|----------|-----------|
| 외식/카페 | 회식 외 개인 외식, 커피 | 빈도 조절 |
| 쇼핑 | 의류, 화장품, 생활용품(필수 외) | 필요 vs 욕구 구분 |
| 여가/문화 | 영화, 공연, 운동, 취미 | 무료/저렴 대안 탐색 |
| 구독서비스 | OTT, 음악, 앱, 잡지 | 정기 정리 |
| 미용 | 미용실, 네일, 피부관리 | 빈도/단가 조절 |
| 경조사 | 축의금, 조의금, 선물 | 상한선 설정 |

#### 저축/투자/부채상환 (20%) - Savings

| 항목 | 우선순위 | 비고 |
|------|---------|------|
| 비상자금 | 1순위 (목표 미달 시) | 3~6개월분 확보까지 |
| 고금리 부채상환 | 1순위 (연 7%+) | 투자보다 상환이 유리 |
| 연금저축/IRP | 2순위 | 세액공제 한도까지 |
| 목표 저축 | 3순위 | 주택, 교육, 결혼 등 |
| 투자 | 4순위 | 비상금 확보 후 |

### 항아리 예산법 상세

**실행 방법:**

1. **물리적 분리**: 카테고리별 별도 통장/계좌 개설
2. **월초 배분**: 월급 들어오면 각 계좌로 자동이체
3. **항아리 내 자유**: 각 카테고리 내에서는 자유롭게 사용
4. **이월 규칙**: 남으면 이월 가능, 부족하면 다른 항아리에서 차감 불가

**계좌 구성 예시:**

| 계좌 | 용도 | 비고 |
|------|------|------|
| A통장 (급여) | 급여 수령 → 즉시 분배 | 잔액 최소 유지 |
| B통장 (고정비) | 주거, 보험, 대출, 공과금 | 자동납부 연결 |
| C통장 (생활비) | 식비, 교통, 일상 | 체크카드 연결 |
| D통장 (저축) | 비상금, 목표 저축 | 인출 불편하게 설정 |
| E통장 (투자) | 연금, 투자 계좌 | 자동이체 |
| F통장 (용돈) | 개인 자유 지출 | 부부 각각 |

## 저축률 목표 설정

### 소득수준별 저축률 가이드

| 월 소득 (실수령) | 최소 저축률 | 권장 저축률 | 가능 저축액/월 |
|-----------------|-----------|-----------|-------------|
| 200만원 | 10% (20만) | 20% (40만) | 20~40만원 |
| 300만원 | 15% (45만) | 25% (75만) | 45~75만원 |
| 400만원 | 15% (60만) | 30% (120만) | 60~120만원 |
| 500만원 | 20% (100만) | 30% (150만) | 100~150만원 |
| 700만원 | 20% (140만) | 35% (245만) | 140~245만원 |
| 1,000만원+ | 25% (250만) | 40% (400만) | 250~400만원 |

### 저축률 높이기 단계별 전략

**1단계: 현재 저축률 파악 (1개월)**
- 모든 수입과 지출 기록
- 현재 저축률 = 실제 저축액 / 총수입 × 100

**2단계: 목표 저축률 설정 (즉시)**
- 현재 + 5%p 상향을 첫 목표로
- 예: 현재 10% → 목표 15%

**3단계: 자동이체 설정 (1주일 내)**
- 목표 저축액을 월급일에 자동이체
- 나머지 금액으로 생활하는 연습

**4단계: 지출 최적화 (1~3개월)**
- 고정비 점검 및 절감 (통신비, 보험, 구독)
- 변동비 중 절감 가능 항목 식별
- 라테 팩터 제거

**5단계: 수입 증대 (3~6개월)**
- 부업, 프리랜서 소득 창출
- 본업 성과 향상 → 연봉 협상
- 불용 자산 매각

## 비상자금 상세 가이드

### 적정 규모 산출

```
비상자금 목표 = 월 필수 지출 × 적정 개월 수
```

| 가구 유형 | 적정 개월 | 근거 |
|----------|----------|------|
| 맞벌이 + 정규직 | 3~6개월 | 두 사람 동시 실직 확률 낮음 |
| 외벌이 + 정규직 | 6~9개월 | 재취업 평균 기간 고려 |
| 외벌이 + 계약직 | 9~12개월 | 고용 불안정 |
| 자영업자 | 6~12개월 | 매출 변동성 |
| 프리랜서 | 6~12개월 | 소득 불규칙 |
| 은퇴자 | 12~24개월 | 재취업 어려움, 의료비 |

### 월 필수 지출 산정

비상자금 기준이 되는 "월 필수 지출"은 최소 생존 비용:

| 포함 항목 | 제외 항목 |
|----------|----------|
| 주거비 (월세/대출) | 여가/문화비 |
| 식비 (최소) | 외식비 |
| 교통비 (기본) | 쇼핑 |
| 공과금 | 구독서비스 |
| 의료비 (기본) | 사교육비 (일부) |
| 보험료 (필수) | 경조사비 |

### 비상자금 축적 전략

| 단계 | 목표 | 기간 | 방법 |
|------|------|------|------|
| 1단계 | 1개월분 | 1~2개월 | 지출 대폭 절감, 불용품 매각 |
| 2단계 | 3개월분 | 3~6개월 | 월 소득 10% 자동이체 |
| 3단계 | 6개월분 | 6~12개월 | 보너스/성과급 전액 투입 |
| 유지 | 목표 유지 | 지속 | 사용 시 즉시 보충 |

### 비상자금 보관 전략

| 구분 | 금액 | 상품 | 수익률 | 인출 |
|------|------|------|-------|------|
| 즉시 인출 | 1개월분 | 입출금통장/CMA | 연 1~2% | 즉시 |
| 1일 내 인출 | 2개월분 | 파킹통장/MMF | 연 2~3% | 당일~익일 |
| 3일 내 인출 | 3개월분 | 단기 정기예금 | 연 3~4% | 중도해지 |

**핵심: 수익률보다 유동성이 우선. 비상자금은 투자가 아니라 보험이다.**

## 자동이체 설정 전략

### 월급일 기준 자동이체 스케줄

```
D-Day (월급일)
├── 저축/투자 자동이체 실행
│   ├── 비상자금 적금
│   ├── 연금저축
│   ├── IRP
│   └── 적립식 투자
│
D+1 (월급일 다음날)
├── 목표 저축 자동이체
│   ├── 주택자금
│   ├── 교육자금
│   └── 기타 목표
│
D+5
├── 고정비 자동납부
│   ├── 보험료
│   ├── 통신비
│   └── 구독료
│
D+25 (월말)
├── 공과금 자동납부
└── 잔액 확인 → 다음달 예산 조정
```

### 자동이체 설정 체크리스트

- [ ] 월급일에 저축/투자 자동이체 설정 완료
- [ ] 연금저축 월 납입액 설정 (월 33만원 = 연 400만원 한도)
- [ ] IRP 월 납입액 설정 (월 25만원 = 연 300만원 추가)
- [ ] 비상자금 적금 자동이체 설정
- [ ] 적립식 투자 자동매수 설정
- [ ] 고정비 자동납부 설정
- [ ] 부부 각각 개인 용돈 자동이체

### 자동이체 금액 조정 시점

| 시점 | 조정 내용 |
|------|----------|
| 연봉 인상 시 | 인상분의 50% 이상을 저축/투자 증액 |
| 부채 상환 완료 시 | 상환액 전액을 저축/투자로 전환 |
| 보너스/성과급 | 최소 50%는 저축/투자 (나머지는 보상) |
| 자녀 독립 시 | 교육비분을 은퇴 저축으로 전환 |
| 지출 절감 성공 시 | 절감액을 자동이체에 반영 |

## 재무 목표 SMART 설정 상세

### SMART 목표 작성 워크시트

**목표 1: _______________**

| 요소 | 질문 | 작성 |
|------|------|------|
| S | 정확히 무엇을 달성하려는가? | |
| M | 어떤 숫자로 측정할 수 있는가? | |
| A | 현재 소득/지출로 가능한가? | |
| R | 나의 삶에 왜 중요한가? | |
| T | 언제까지 달성할 것인가? | |

**예시:**

```
목표: 2027년 6월까지 전세 보증금 2억원 마련
S: 서울 25평 아파트 전세 보증금 2억원
M: 현재 5,000만원 → 목표 2억원 (부족분 1.5억원)
A: 월 300만원 저축 × 36개월 = 1.08억 + 투자수익
   부모 지원 5,000만원 예상
R: 결혼 후 안정적 주거 확보
T: 2027년 6월 (3년 후)
월 필요 저축액: 약 300만원
```

## 예산 관리 실전 팁

### 예산 실패를 방지하는 7가지 원칙

1. **현실적 시작**: 현재 지출의 5~10%만 줄이는 것부터
2. **버퍼 확보**: 예상치 못한 지출 대비 예산의 5~10% 여유분
3. **우선순위 명확**: 모든 지출을 동시에 줄이지 말고 상위 3개 항목 집중
4. **보상 설계**: 월 목표 달성 시 소소한 보상 (용돈의 일부)
5. **추적 간소화**: 매일 기록이 부담이면 주 1회 정산
6. **파트너 동의**: 부부가 함께 예산 수립하고 리뷰
7. **유연성 허용**: 월 1~2회 예산 초과는 허용, 월말 정산으로 조정

### 예산 리뷰 주기

| 주기 | 내용 | 소요 시간 |
|------|------|----------|
| 주간 | 지출 기록 확인, 예산 대비 진행률 | 10분 |
| 월간 | 전월 지출 분석, 예산 vs 실적 비교 | 30분 |
| 분기 | 저축률 점검, 재무 목표 진행률 확인 | 1시간 |
| 연간 | 연간 수입/지출 총정리, 다음해 예산 수립 | 2~3시간 |

### 가계부 앱 활용 가이드

**자동 분류 앱 활용 포인트:**
- 카드 사용 내역 자동 연동 (뱅크샐러드, 토스 등)
- 현금 사용분은 수동 입력 (최소화 권장)
- 카테고리 커스텀 설정 (본인 예산 카테고리와 일치)
- 월말 자동 리포트로 지출 패턴 확인

**수동 기록 방법 (앱 사용 어려울 시):**
- 구글 스프레드시트/엑셀 월별 시트
- 위 템플릿 활용하여 주 1회 정산
- 카드 명세서 + 통장 내역 기반 기록
