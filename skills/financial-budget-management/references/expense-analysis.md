## 지출 분석 방법

### 고정/변동/선택 지출 3분류법

모든 지출을 3가지로 분류하여 절감 가능성 판단:

#### 고정 지출 (Fixed Expenses)

계약이나 약정으로 매월 일정한 금액이 나가는 지출:

| 항목 | 절감 방법 | 절감 효과 |
|------|----------|----------|
| 월세 | 이사, 다운사이징 | 대 (실행 어려움) |
| 대출 원리금 | 대환대출, 금리 협상 | 중~대 |
| 보험료 | 보장 분석 후 정리 | 중 |
| 통신비 | 요금제 변경, 알뜰폰 | 중 |
| 학원비 | 효과 점검 후 조정 | 중 |
| 구독료 | 미사용 해지 | 소~중 |

**고정 지출 절감 전략:**
- 연 1회 이상 모든 고정 지출 항목 재검토
- "이 지출이 없다면 삶에 큰 영향이 있는가?" 질문
- 자동 갱신되는 계약/구독 목록 작성 및 관리

#### 변동 필수 지출 (Variable Necessities)

생활에 필요하지만 금액이 매월 변하는 지출:

| 항목 | 절감 방법 | 절감 효과 |
|------|----------|----------|
| 식비 (장보기) | 식단 계획, 대량구매, 시장 이용 | 중 |
| 교통비 | 대중교통, 카풀, 자전거 | 소~중 |
| 공과금 | 에너지 절약 습관, 할인 제도 | 소 |
| 의료비 | 예방 관리, 실손보험 활용 | 변동 |
| 생필품 | 할인 시 대량 구매, 대체재 | 소 |

**변동 필수 지출 절감 전략:**
- 카테고리별 월 상한선 설정
- 3개월 평균 대비 10% 절감 목표
- 대체재/대안 탐색 (브랜드 → PB, 외식 → 집밥)

#### 선택 지출 (Discretionary)

없어도 생활에 지장 없는 지출:

| 항목 | 절감 방법 | 절감 효과 |
|------|----------|----------|
| 외식/카페 | 빈도 제한 (주 2회 → 1회) | 중 |
| 쇼핑 (비필수) | 24시간 대기 룰, 위시리스트 | 중~대 |
| 배달 음식 | 빈도 제한, 직접 조리 | 중 |
| 택시 | 대중교통 대체 | 소~중 |
| 유흥/오락 | 예산 내 계획 지출 | 소~중 |

**선택 지출 절감 전략:**
- 24시간 룰: 구매 충동 시 24시간 대기 후 결정
- 지출 일기: "왜 이것을 샀는가?" 감정 기록
- 무지출 챌린지: 주 1~2일 지출 제로 데이

### 지출 분석 실전 절차

**1단계: 데이터 수집 (1개월)**

```
수집 소스:
├── 신용카드 명세서 (모든 카드)
├── 체크카드 이용내역
├── 자동이체 내역
├── 현금 영수증 내역
└── 모바일페이 내역
```

**2단계: 분류 (1일)**
- 모든 지출을 고정/변동필수/선택으로 분류
- 각 카테고리별 소계 산출
- 전체 비율 확인

**3단계: 분석 (1일)**

| 질문 | 확인 내용 |
|------|----------|
| 소득 대비 지출 비율은? | 총 지출 / 총 수입 × 100 |
| 가장 큰 지출 항목 3개는? | 상위 3개 항목 확인 |
| 선택 지출 비율은? | 30% 이내인가? |
| 불필요한 반복 지출은? | 라테 팩터 발견 |
| 전월 대비 증가 항목은? | 증가 원인 파악 |

**4단계: 개선 계획 (즉시)**
- 상위 3개 과다 지출 항목에 집중
- 각 항목별 구체적 절감 목표 설정
- 실행 방법 결정 및 자동화

## 라테 팩터 분석

### 라테 팩터란?

데이비드 바흐(David Bach)가 제시한 개념으로, 습관적으로 반복되는 소액 지출이 장기적으로 큰 금액이 되는 현상.

### 한국 가정의 주요 라테 팩터

| 항목 | 1회 금액 | 빈도 | 월 누적 | 연 누적 |
|------|---------|------|--------|--------|
| 카페 커피 | 4,500~6,000원 | 주 5회 | 9~12만원 | 108~144만원 |
| 편의점 간식/음료 | 2,000~5,000원 | 주 3~5회 | 3~10만원 | 36~120만원 |
| 배달 음식 (2인 기준) | 25,000~40,000원 | 주 2~3회 | 20~48만원 | 240~576만원 |
| 택시 | 8,000~15,000원 | 주 1~2회 | 3~12만원 | 36~144만원 |
| 충동 온라인 쇼핑 | 10,000~30,000원 | 월 3~5회 | 3~15만원 | 36~180만원 |
| 게임 과금/인앱 결제 | 5,000~30,000원 | 월 2~4회 | 1~12만원 | 12~144만원 |
| 로또/복권 | 5,000~10,000원 | 주 1회 | 2~4만원 | 24~48만원 |

### 라테 팩터의 기회비용

```
월 10만원의 라테 팩터를 투자했다면 (연 7% 수익률):

 5년 후: 약  720만원
10년 후: 약 1,730만원
20년 후: 약 5,200만원
30년 후: 약 12,200만원
```

### 라테 팩터 제거 전략

| 단계 | 방법 | 설명 |
|------|------|------|
| 1 | 인식 | 2주간 모든 소액 지출을 기록하고 총액 확인 |
| 2 | 우선순위 | 상위 3개 라테 팩터 선정 |
| 3 | 대안 설정 | 카페 커피 → 텀블러, 배달 → 집밥 등 |
| 4 | 점진적 줄이기 | 즉시 전면 차단 X → 빈도 50% 감소부터 |
| 5 | 자동 저축 | 절감분을 자동이체로 저축 계좌로 전환 |

### 구독 정리 판단 기준

| 기준 | 유지 | 해지 고려 |
|------|------|----------|
| 사용 빈도 | 주 2회 이상 | 월 2회 이하 |

### 구독 최적화 전략

1. **번갈아 구독**: OTT 서비스를 2~3개월 단위로 번갈아 가입
2. **가족 요금제**: 부부/가족이 함께 쓸 수 있는 요금제 활용
3. **연간 결제**: 월 결제 대비 15~30% 할인 (확실히 사용할 서비스만)
4. **무료 체험 관리**: 체험 종료일 캘린더 등록, 자동결제 전 해지 판단
5. **분기별 점검**: 3개월마다 모든 구독 서비스 리스트 점검

## 카드 사용 최적화

### 신용카드 vs 체크카드

| 구분 | 신용카드 | 체크카드 |
|------|---------|---------|
| 소득공제 | 15% | 30% |
| 혜택 | 포인트/마일리지/할인 | 혜택 적음 |
| 과소비 위험 | 높음 | 낮음 |
| 적합 대상 | 자기관리 가능한 경우 | 소비 통제 필요 시 |

### 소득공제 최적화 전략

```
연간 카드 소득공제 한도: 총급여의 25% 초과분
- 25% 이하: 공제 없음 (기본 사용분)
- 25% 초과분: 신용카드 15%, 체크카드/현금영수증 30%

전략:
1단계: 총급여 25%까지는 신용카드 (혜택 극대화)
2단계: 25% 초과분은 체크카드 (소득공제율 2배)
```

**예시 (연봉 5,000만원 기준):**
```
25% = 1,250만원 → 신용카드로 사용 (혜택 극대화)
초과분 → 체크카드로 사용 (공제율 30%)
```

### 카드 혜택 활용 전략

| 지출 유형 | 추천 카드 유형 | 예상 할인율 |
|----------|--------------|-----------|
| 식비/마트 | 대형마트 제휴 카드 | 5~10% |
| 주유 | 정유사 제휴 카드 | 5~7%/L |
| 대중교통 | 교통 특화 카드 | 10~15% |
| 통신비 | 통신사 제휴 카드 | 10~15% |
| 온라인 쇼핑 | 쇼핑 특화 카드 | 5~10% |
| 해외 결제 | 해외 수수료 없는 카드 | 1~2% (수수료 절감) |

### 카드 관리 원칙

1. **카드 2~3장 이내**: 주력 1장 + 보조 1~2장
2. **실적 조건 확인**: 최소 실적 달성 가능한 카드만 유지
3. **연회비 대비 혜택**: 연회비 > 혜택이면 무료 카드 전환
4. **리볼빙/할부 금지**: 연 15~20% 이자, 절대 사용 금지
5. **한도 관리**: 월 소득 이하로 한도 설정

## 맞벌이 가계 관리 전략

### 가계비 관리 3가지 모델

#### 모델 1: 공동계좌형

```
배우자A 급여 ─┐
              ├──→ 공동계좌 ──→ 모든 지출/저축
배우자B 급여 ─┘
              ├──→ 개인용돈 A (각자 관리)
              └──→ 개인용돈 B (각자 관리)
```

| 장점 | 단점 |
|------|------|
| 투명한 관리 | 개인 자유도 낮음 |
| 목표 관리 용이 | 합의 필요 사항 많음 |
| 누락 없는 전체 파악 | 소비 갈등 가능 |

#### 모델 2: 비율분담형

```
배우자A 급여 ──→ 소득 비율에 따라 공동비용 분담
                + 나머지 개인 관리
배우자B 급여 ──→ 소득 비율에 따라 공동비용 분담
                + 나머지 개인 관리
```

| 장점 | 단점 |
|------|------|
| 소득 차이 공정 반영 | 전체 재무 파악 어려움 |
| 개인 자유도 높음 | 저축 목표 관리 약함 |
| 갈등 적음 | 한쪽 과소비 모를 수 있음 |

#### 모델 3: 역할분담형

```
배우자A 급여 ──→ 고정비 (주거, 보험, 대출) 담당
배우자B 급여 ──→ 변동비 (식비, 생활) + 저축 담당
```

| 장점 | 단점 |
|------|------|
| 역할 명확 | 소득 변동 시 불균형 |
| 관리 간편 | 전체 파악 어려울 수 있음 |

### 맞벌이 가계 관리 권장 방식

**하이브리드 모델 (공동계좌 + 개인용돈):**

```
배우자A 급여: 400만원
배우자B 급여: 300만원
합계: 700만원

공동계좌 이체:
├── A: 340만원 (급여의 85%)
├── B: 255만원 (급여의 85%)
└── 공동계좌 합계: 595만원

공동계좌에서:
├── 고정비: 250만원
├── 변동비: 150만원
├── 저축/투자: 175만원
└── 예비비: 20만원

개인용돈:
├── A: 60만원 (급여의 15%)
└── B: 45만원 (급여의 15%)
```

### 맞벌이 가계 점검 회의

**월 1회 가계 회의 안건:**

| 순서 | 안건 | 소요 시간 |
|------|------|----------|
| 1 | 전월 수입/지출 결산 | 10분 |
| 2 | 예산 대비 실적 비교 | 5분 |
| 3 | 재무 목표 진행률 확인 | 5분 |
| 4 | 다음달 특별 지출 예고 | 5분 |
| 5 | 조정 사항 합의 | 5분 |
| | **합계** | **30분** |

### 맞벌이 핵심 원칙

1. **투명성**: 서로의 소득/자산/부채를 공유
2. **공정성**: 소득 비율에 따른 기여, 절대 금액이 아닌 비율
3. **자율성**: 개인 용돈은 간섭 없이 자유 사용
4. **공동 목표**: 주택, 교육, 은퇴 등 공동 목표 함께 설정
5. **정기 소통**: 월 1회 가계 회의로 현황 공유 및 조율
