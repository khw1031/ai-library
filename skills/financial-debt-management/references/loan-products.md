# 대출 상품 상세 가이드

## 1. 주택담보대출

### 1.1 개요

주택을 담보로 자금을 차입하는 대출. 가계 부채에서 가장 큰 비중을 차지합니다.

### 1.2 금리 유형별 비교

| 유형 | 금리 범위 (2025년 기준) | 특징 | 적합한 차주 |
|------|----------------------|------|------------|
| 고정금리 | 3.5~5.0% | 전 기간 금리 고정 | 안정성 선호, 장기 보유 |
| 변동금리 | 3.0~4.5% | 6개월/1년마다 변동 | 단기 보유, 금리 하락 기대 |
| 혼합금리 | 3.3~4.8% | 5년 고정 → 변동 전환 | 중기 안정 선호 |

### 1.3 상환 방식

| 방식 | 월 상환액 | 총 이자 | 특징 |
|------|----------|---------|------|
| **원리금균등** | 매월 동일 | 중간 | 가장 보편적, 자금 계획 용이 |
| **원금균등** | 매월 감소 | 가장 적음 | 초기 부담 크나 총 이자 절감 |
| **만기일시** | 이자만 납부 | 가장 많음 | 단기 자금 필요 시만 권장 |

#### 상환 방식별 비교 (3억, 금리 4%, 30년 기준)

| 항목 | 원리금균등 | 원금균등 | 만기일시 |
|------|----------|---------|---------|
| 1회차 월 상환 | 약 143만원 | 약 183만원 | 100만원 (이자만) |
| 마지막 월 상환 | 약 143만원 | 약 84만원 | 3억 + 100만원 |
| 총 이자 | 약 2.15억원 | 약 1.81억원 | 약 3.6억원 |
| 총 상환액 | 약 5.15억원 | 약 4.81억원 | 약 6.6억원 |

**권장**: 원리금균등 또는 원금균등 선택. 만기일시는 투자 목적 외에는 비추천.

### 1.4 주담대 가입 시 주요 고려사항

#### 중도상환수수료

| 기간 | 수수료율 | 비고 |
|------|---------|------|
| 대출 후 1년 이내 | 1.2~1.5% | 높은 수수료 |
| 대출 후 1~3년 | 0.8~1.2% | 체감 적용 |
| 대출 후 3년 이후 | 0% | 면제 (대부분) |

**핵심**: 대환대출(갈아타기) 시 중도상환수수료를 반드시 확인

#### 금리 인하 요구권

```
[금리 인하 요구권이란]
대출 후 신용도가 개선되면 금리 인하를 요구할 수 있는 법적 권리

[요구 가능 사유]
- 승진/연봉 인상으로 소득 증가
- 신용점수 상승
- 재산 증가 (부동산 추가 취득 등)
- 기존 대출 상환으로 부채 감소

[방법]
금융사 앱/전화로 신청 → 심사 → 금리 인하 (0.1~0.5%p)
연 1회 이상 시도 권장
```

### 1.5 대출 한도 계산

```
[LTV 기반 한도]
대출 한도 = 주택 감정가 x LTV 비율
예: 5억 아파트, LTV 70% → 최대 3.5억

[DSR 기반 한도]
연간 상환 가능액 = 연소득 x DSR 40%
대출 가능액 = 연간 상환 가능액으로 역산
예: 연소득 6,000만원 → 연 상환 2,400만원 → 대출 약 4억 (30년, 4%)

[실제 한도 = min(LTV 한도, DSR 한도)]
```

## 2. 전세자금대출

### 2.1 개요

전세 보증금 마련을 위한 대출. 주거 안정을 위한 핵심 대출 상품.

### 2.2 유형별 비교

| 유형 | 대상 | 금리 | 한도 | 특징 |
|------|------|------|------|------|
| 은행 전세대출 | 일반 | 3.5~5.0% | 전세금의 70~80% | 소득/신용 기반 |
| 버팀목 전세대출 | 저소득/무주택 | 1.8~2.7% | 수도권 1.2억, 기타 8천만원 | 정책금융 |
| 카카오/네이버 전세대출 | 일반 | 은행과 유사 | 전세금의 70~80% | 비대면 편의 |
| 주택도시기금 전세대출 | 무주택 세대주 | 1.2~2.1% | 최대 3억 | 소득 요건 있음 |

### 2.3 전세대출 주의사항

#### 전세사기 예방 체크리스트

```
□ 등기부등본 확인 (근저당, 가압류, 가등기 확인)
□ 건물 감정가 대비 전세가율 확인 (80% 이하 안전)
□ 집주인 세금 체납 여부 확인 (국세/지방세 완납 증명)
□ 전입신고 + 확정일자 즉시 (대항력/우선변제권 확보)
□ 전세보증보험 가입 (HUG, SGI 등)
□ 신탁등기 여부 확인 (신탁된 물건은 신탁사 동의 필요)
□ 다가구 vs 다세대 구분 (다가구는 소액보증금 우선변제만)
```

#### 전세가율 안전 기준

| 전세가율 | 판단 | 조치 |
|---------|------|------|
| 60% 이하 | 안전 | 정상 진행 |
| 60~70% | 양호 | 보증보험 가입 |
| 70~80% | 주의 | 보증보험 필수, 집주인 재무상태 확인 |
| 80% 이상 | 위험 | 계약 재고, 다른 물건 검토 |

### 2.4 전세대출 갱신 전략

```
[만기 전 체크리스트]
1. 3개월 전: 전세 갱신/이사 결정
2. 2개월 전: 대출 연장 또는 신규 대출 비교
3. 1개월 전: 연장 신청 또는 대환대출 실행
4. 만기일: 기존 대출 상환 완료 확인

[갱신 vs 이사 판단]
- 전세금 인상률 5% 이내: 갱신 유리 (계약갱신청구권)
- 전세금 인상 + 대출 금리 상승: 총 비용 비교 후 판단
- 전세가율 80% 초과: 이사 검토
```

## 3. 신용대출

### 3.1 개요

담보 없이 신용만으로 차입하는 대출. 금리가 높으므로 단기적/소액으로만 활용.

### 3.2 유형별 비교

| 유형 | 금리 범위 | 한도 | 특징 |
|------|----------|------|------|
| 은행 신용대출 | 4~7% | 연소득의 100~150% | 가장 유리한 조건 |
| 인터넷은행 신용대출 | 4~10% | 다양 | 비대면, 빠른 심사 |
| 저축은행 신용대출 | 8~15% | 다양 | 은행 거절 시 대안 |
| 카드론 | 10~18% | 카드 한도 내 | 긴급 시만, 즉시 상환 |
| 현금서비스 | 15~20% | 소액 | 최후 수단, 신용점수 악영향 |

### 3.3 신용대출 활용 원칙

```
[원칙 1] 소비 목적 신용대출은 피한다
  → 여행, 쇼핑, 경조사 등을 위한 신용대출 지양

[원칙 2] 단기 상환 계획을 세운다
  → 12개월 이내 완납 목표

[원칙 3] 주담대/전세대출 계획이 있다면 신용대출 자제
  → DSR에 포함되어 주담대 한도 감소

[원칙 4] 금리 비교 후 가장 낮은 금리로
  → 은행 > 인터넷은행 > 저축은행 순서로 시도

[원칙 5] 여러 은행 동시 조회 주의
  → 단기간 다수 조회 시 신용점수 하락 가능
  → "가조회" 서비스 활용 (신용점수 영향 없음)
```

### 3.4 마이너스 통장 vs 일반 신용대출

| 항목 | 마이너스 통장 | 일반 신용대출 |
|------|-------------|-------------|
| 금리 | 일반 대비 0.5~1% 높음 | 상대적으로 낮음 |
| 이자 계산 | 사용한 금액만 일할 이자 | 전체 대출금에 이자 |
| 유연성 | 수시 인출/상환 | 정해진 상환 스케줄 |
| 적합한 상황 | 일시적 자금 필요, 비상자금 | 확정된 자금 필요 |

## 4. 정책금융 (정부 지원 대출)

### 4.1 디딤돌 대출

**대상**: 무주택 세대주, 부부 합산 연소득 6천만원 이하 (생애최초 시 7천만원)

| 항목 | 내용 |
|------|------|
| 대상 주택 | 5억원 이하 (수도권), 3억원 이하 (기타) |
| 대출 한도 | 최대 2.6억원 |
| 금리 | 연 2.15~3.00% (소득/조건별 차등) |
| 상환 기간 | 10년/15년/20년/30년 |
| 상환 방식 | 원리금균등, 원금균등, 체증식 |

**우대 금리 조건**:
- 신혼부부: 0.2%p 우대
- 다자녀 (2자녀 이상): 0.5%p 우대
- 한부모 가구: 0.5%p 우대
- 생애최초: 0.2%p 우대

### 4.2 버팀목 전세대출

**대상**: 무주택 세대주, 부부 합산 연소득 5천만원 이하

| 항목 | 내용 |
|------|------|
| 대상 주택 | 전세금 수도권 3억, 기타 2억 이하 |
| 대출 한도 | 수도권 1.2억, 기타 8천만원 |
| 금리 | 연 1.8~2.7% (소득별 차등) |
| 대출 기간 | 2년 (4회 연장, 최대 10년) |

### 4.3 신생아 특례 대출

**대상**: 대출 신청일 기준 2년 이내 출산 가구 (2023.1.1 이후 출생아)

#### 신생아 특례 구입자금 대출

| 항목 | 내용 |
|------|------|
| 소득 요건 | 부부 합산 연소득 1.3억원 이하 |
| 자산 요건 | 순자산 4.69억원 이하 |
| 대상 주택 | 9억원 이하 |
| 대출 한도 | 최대 5억원 |
| 금리 | 연 1.6~3.3% (소득별 차등) |
| 상환 기간 | 10/15/20/30년 |

#### 신생아 특례 전세자금 대출

| 항목 | 내용 |
|------|------|
| 소득 요건 | 부부 합산 연소득 1.3억원 이하 |
| 대상 주택 | 보증금 수도권 5억, 기타 4억 이하 |
| 대출 한도 | 최대 3억원 |
| 금리 | 연 1.1~3.0% (소득별 차등) |

### 4.4 특례보금자리론

**대상**: 무주택자 또는 1주택자 (처분 조건부)

| 항목 | 내용 |
|------|------|
| 소득 요건 | 부부 합산 연소득 7천만원 이하 |
| 대상 주택 | 6억원 이하 |
| 대출 한도 | 최대 3.6억원 |
| 금리 | 고정금리 (시기별 변동) |
| 상환 기간 | 10/15/20/30/40/50년 |

### 4.5 정책금융 선택 가이드

```
[주택 구입 시]

무주택 + 연소득 6천만원 이하 + 5억 이하 주택
  → 디딤돌 대출

2년 내 출산 + 연소득 1.3억 이하 + 9억 이하 주택
  → 신생아 특례 구입자금

무주택/1주택 + 연소득 7천만원 이하 + 6억 이하 주택
  → 특례보금자리론

위 요건 미충족
  → 시중은행 주담대 (금리 비교)


[전세 시]

무주택 + 연소득 5천만원 이하
  → 버팀목 전세대출

2년 내 출산 + 연소득 1.3억 이하
  → 신생아 특례 전세대출

위 요건 미충족
  → 시중은행 전세대출
```

### 4.6 정책금융 주의사항

1. **소득 기준**: 대부분 부부 합산 소득 기준 (맞벌이 시 소득 합산)
2. **주택 가격 상한**: 대상 주택 가격 제한 있음
3. **거주 의무**: 실거주 요건 있음 (대출 실행 후 전입 필요)
4. **중도상환수수료**: 일부 상품은 3년 이내 중도상환 시 수수료 부과
5. **기한 연장**: 전세대출은 2년 단위 연장, 연장 요건 충족 필요
6. **정책 변경**: 정부 정책에 따라 조건 수시 변경되므로 최신 정보 확인 필수
