# 상환 전략 상세 가이드

## 1. 상환 전략 (눈덩이 vs 눈사태)

### 1.1 눈덩이 방법 (Debt Snowball)

잔액이 가장 적은 대출부터 집중 상환하는 방법.

#### 실행 방법

```
1단계: 모든 대출을 잔액 오름차순으로 정렬
2단계: 모든 대출에 최소 상환액 납부
3단계: 여유 자금을 잔액 가장 적은 대출에 집중
4단계: 첫 번째 대출 완납 후, 그 상환액을 다음 대출에 추가
5단계: 반복
```

#### 예시

```
[대출 현황]
A. 카드론 200만원 (금리 15%, 최소 상환 5만원/월)
B. 신용대출 1,000만원 (금리 6%, 최소 상환 20만원/월)
C. 전세대출 5,000만원 (금리 3.5%, 최소 상환 30만원/월)

[월 가용 상환액: 80만원]

눈덩이 순서: A → B → C

1개월차: A에 30만원 집중 (5+25), B 20만원, C 30만원
약 7개월: A 완납
8개월차~: B에 50만원 (20+30), C 30만원
약 24개월: B 완납
25개월차~: C에 80만원 전액 집중
```

**장점**: 빠른 첫 완납 → 성취감 → 동기부여 → 지속력
**단점**: 총 이자 비용이 눈사태 대비 높음

### 1.2 눈사태 방법 (Debt Avalanche)

금리가 가장 높은 대출부터 집중 상환하는 방법.

#### 실행 방법

```
1단계: 모든 대출을 금리 내림차순으로 정렬
2단계: 모든 대출에 최소 상환액 납부
3단계: 여유 자금을 금리 가장 높은 대출에 집중
4단계: 첫 번째 대출 완납 후, 그 상환액을 다음 대출에 추가
5단계: 반복
```

#### 동일 예시로 비교

```
눈사태 순서: A(15%) → B(6%) → C(3.5%)

이 경우 눈덩이와 동일한 순서!
(잔액 적은 것이 금리도 높은 경우)

만약 금리가 다르다면:
A. 신용대출 1,000만원 (금리 12%)  ← 금리 최고, 먼저 상환
B. 카드론 200만원 (금리 8%)
C. 전세대출 5,000만원 (금리 3.5%)
```

**장점**: 총 이자 비용 최소화 (수학적 최적)
**단점**: 첫 완납까지 시간이 오래 걸릴 수 있음

### 1.3 하이브리드 전략

```
[권장 전략]
1. 초고금리 대출 (연 10% 이상)은 금리순(눈사태)으로 최우선 상환
2. 중금리 대출 (연 5~10%) 중에서는 잔액 적은 것(눈덩이)부터
3. 저금리 대출 (연 5% 미만)은 정상 상환 유지
```

## 2. 대출 갈아타기 (대환대출)

### 2.1 대환대출이란

기존 대출을 금리가 더 낮은 새 대출로 교체하는 것.

### 2.2 대환대출 판단 기준

#### 손익분기점 계산

```
[대환대출이 유리한 조건]

절감 이자 > 비용 (중도상환수수료 + 대환 부대비용)

절감 이자 = 대출 잔액 x (기존 금리 - 신규 금리) x 잔여 기간
비용 = 중도상환수수료 + 인지세 + 감정평가비 + 기타

예시:
잔액 2억, 기존 5%, 신규 3.5%, 잔여 20년, 중도상환수수료 0.5%

연간 절감 이자 = 2억 x 1.5% = 300만원
중도상환수수료 = 2억 x 0.5% = 100만원
기타 비용 = 약 50만원

손익분기 기간 = 150만원 / 300만원 = 약 6개월
→ 6개월 이후부터 이득 → 대환 실행 권장
```

### 2.3 대환대출 체크리스트

```
□ 금리 차이가 0.5%p 이상인가?
□ 잔여 상환 기간이 5년 이상 남았는가?
□ 중도상환수수료 기간이 지났는가? (3년 경과 여부)
□ 대환 시 총 비용 (수수료 + 부대비용) 계산했는가?
□ 손익분기 기간이 2년 이내인가?
□ 대환 후 새 대출 조건 (금리 유형, 상환 방식) 확인했는가?
□ 신용점수가 대환에 영향 없는가?
```

### 2.4 대환대출 유형

| 유형 | 내용 | 주의사항 |
|------|------|---------|
| 주담대 → 주담대 | 금리 인하 목적 | 근저당 변경 비용 발생 |
| 신용대출 → 신용대출 | 금리 인하 | 기존 대출 상환 확인서 필요 |
| 고금리 → 저금리 | 2금융권 → 은행 | 신용점수 개선 후 시도 |
| 변동 → 고정 | 금리 상승 방어 | 고정 금리가 현재 변동보다 높을 수 있음 |
| 고정 → 변동 | 금리 하락 수혜 | 향후 금리 상승 리스크 |

### 2.5 대환대출 플랫폼

```
[온라인 대환 서비스]
- 대환대출 비교 플랫폼: 토스, 카카오페이, 네이버 금융
- 한국주택금융공사 안심전환대출: 변동금리 → 고정금리 전환
- 금융위원회 대환대출 인프라: 온라인 비대면 대환

[활용 팁]
1. 여러 플랫폼에서 "가조회"로 금리 비교 (신용점수 영향 없음)
2. 가조회 결과와 실제 금리는 다를 수 있음
3. 최저금리만 보지 말고 총 비용 (수수료 포함) 비교
```

## 3. 부채 건전성 지표 상세

### 3.1 부채비율 상세

```
부채비율 = 총 부채 / 총 자산 x 100

[총 부채]
- 주택담보대출 잔액
- 전세자금대출 잔액
- 신용대출 잔액
- 자동차 할부 잔액
- 학자금 대출 잔액
- 카드론/현금서비스 잔액
- 기타 차입금

[총 자산]
- 부동산 (시가)
- 전세 보증금
- 예적금
- 투자자산 (주식, 펀드, 채권 등)
- 퇴직금 (예상)
- 보험 해약환급금
- 기타 자산
```

#### 부채비율 해석

| 비율 | 등급 | 의미 | 조치 |
|------|------|------|------|
| 0~20% | 우수 | 매우 건전 | 현 상태 유지 |
| 20~30% | 양호 | 건전 | 관리하며 유지 |
| 30~50% | 보통 | 주의 필요 | 부채 축소 계획 수립 |
| 50~70% | 주의 | 위험 접근 | 적극적 부채 상환 |
| 70% 이상 | 위험 | 재무 위기 | 즉각 대응 필요 |

### 3.2 DTI 상세 계산

```
DTI = 주담대 연간 원리금 상환액 / 연 총소득 x 100

[연간 원리금 상환액]
= 월 원리금 상환액 x 12

[연 총소득]
= 근로소득 + 사업소득 + 임대소득 + 이자/배당소득 + 연금소득

[예시]
월 주담대 상환: 150만원
연소득: 6,000만원
DTI = (150 x 12) / 6,000 x 100 = 30%
```

### 3.3 DSR 상세 계산

```
DSR = 모든 대출의 연간 원리금 상환액 합계 / 연 총소득 x 100

[포함 대출]
- 주택담보대출 원리금
- 전세대출 원리금 (이자만 납부 시 이자 + 원금 환산액)
- 신용대출 원리금
- 카드론 원리금
- 자동차 할부 원리금
- 학자금 대출 원리금
- 기타 모든 대출

[예시]
주담대 월 상환: 120만원
전세대출 월 이자: 15만원 (원금 환산 포함 약 50만원)
신용대출 월 상환: 30만원
연소득: 7,000만원

DSR = ((120 + 50 + 30) x 12) / 7,000 x 100 = 34.3%
```

**주의**: 전세대출의 DSR 계산 시, 만기일시 상환이더라도 원금 분할 환산하여 계산

### 3.4 부채 건전성 종합 진단표

```
[종합 진단]

        안전        주의         위험
부채비율  |---30%---|---50%---|-------→
DTI     |---30%---|---40%---|-------→
DSR     |---30%---|---40%---|-------→

3개 지표 모두 안전 → 재무 건전
1개 이상 주의 → 모니터링 강화
1개 이상 위험 → 부채 축소 실행
2개 이상 위험 → 긴급 대응 필요
```

## 4. 신용점수 관리 상세

### 4.1 신용점수 체계

| 평가 기관 | 점수 범위 | 등급 체계 |
|-----------|----------|----------|
| NICE (나이스) | 1~1,000점 | 1~10등급 |
| KCB (올크레딧) | 1~1,000점 | 1~10등급 |

#### 등급별 점수 범위 (NICE 기준)

| 등급 | 점수 | 대출 가능성 |
|------|------|------------|
| 1등급 | 900~1,000 | 최우대 금리 가능 |
| 2등급 | 870~899 | 우대 금리 가능 |
| 3등급 | 840~869 | 은행 대출 가능 |
| 4등급 | 805~839 | 은행 대출 가능 (금리 높음) |
| 5등급 | 750~804 | 은행 일부 가능 |
| 6등급 | 665~749 | 2금융권 대출 |
| 7등급 | 600~664 | 저축은행/캐피탈 |
| 8등급 | 515~599 | 대부업 수준 |
| 9등급 | 445~514 | 대출 거의 불가 |
| 10등급 | 0~444 | 대출 불가 |

### 4.2 신용점수 관리 전략

#### 연체 관리 (가장 중요)

```
[연체 영향]

1일 연체: 단기 연체 기록 (영향 적음, 5영업일 이내 해소)
5일 이상 연체: 신용점수 하락 시작
30일 이상 연체: 상당한 점수 하락, 기록 1년 보관
90일 이상 연체: 심각한 점수 하락, 기록 최대 5년 보관

[연체 예방]
1. 모든 납부를 자동이체 설정
2. 급여일 직후 상환일 설정
3. 비상자금 100만원 이상 유지
4. 연체 위험 시 사전에 금융사 연락 (분할 상환 협의)
```

#### 신용카드 관리

```
[최적 사용 전략]

신용카드 이용률 = 이용 금액 / 총 한도 x 100

권장 이용률: 10~30%
예: 한도 500만원 → 월 50~150만원 사용

[주의사항]
- 한도의 70% 이상 사용 시 점수 하락
- 리볼빙 사용은 신용점수에 악영향
- 카드 수 3~4개 적정 (너무 많으면 관리 어려움)
- 장기 미사용 카드는 해지 (단, 가장 오래된 카드는 유지)
```

#### 신용 조회 관리

```
[신용 조회 유형]

개인 조회 (소프트 조회): 점수 영향 없음
  - 본인 신용점수 확인
  - 가조회 (토스, 카카오 등)

기관 조회 (하드 조회): 점수 하락 가능
  - 대출 신청 시 금융사 조회
  - 신용카드 발급 신청

[관리 방법]
- 대출 비교 시 "가조회" 활용
- 1개월 내 여러 건 조회는 하나로 간주 (쇼핑 기간)
- 불필요한 대출/카드 신청 자제
```

### 4.3 신용점수 회복 타임라인

| 상황 | 회복 기간 | 방법 |
|------|----------|------|
| 단기 연체 (30일 미만) | 3~6개월 | 상환 후 성실 납부 |
| 장기 연체 (90일 이상) | 1~3년 | 완납 + 성실 거래 |
| 채무조정 (워크아웃) | 3~5년 | 상환 완료 후 정상 거래 |
| 개인회생 | 5~7년 | 면책 후 신규 거래 시작 |
| 개인파산 | 7~10년 | 면책 후 소액 거래부터 |

## 5. 긴급 부채 관리 상세

### 5.1 연체 시 단계별 대응

#### 연체 전 (위험 감지 시)

```
[즉시 실행]
1. 지출 긴급 삭감 (비필수 지출 전면 중단)
2. 비상자금 활용 가능 여부 확인
3. 가족/지인 일시 차입 검토 (고금리 대출보다 나음)
4. 금융사에 사전 연락 → 상환 유예/분할 협의
5. 프리워크아웃 신청 검토
```

#### 연체 발생 시

```
[즉시 대응]
1. 금융사 즉시 연락 (연체 장기화 방지)
2. 상환 가능한 금액이라도 일부 납부
3. 연체 기간 최소화 (5일 이내 해소 노력)
4. 다른 금융사 연체 파급 방지 (우선순위 정리)

[상환 우선순위]
1순위: 주거 관련 (주담대, 전세대출) - 주거 상실 방지
2순위: 고금리 대출 (카드론, 현금서비스) - 이자 폭증 방지
3순위: 신용대출 - 신용점수 관리
4순위: 학자금/정책금융 - 상대적으로 유예 가능
```

### 5.2 채무조정 제도 상세

#### 프리워크아웃 (사전채무조정)

```
[대상] 연체 30일 이내 또는 연체 발생 전 (상환 곤란 예상)
[신청] 신용회복위원회 (1600-5500)
[효과]
- 이자율 감면 (약정 이자의 50% 감면)
- 상환 기간 연장 (최장 10년)
- 채무 감면 없음 (원금은 전액 상환)
[장점] 연체 전 신청 가능, 신용점수 영향 최소화
```

#### 개인워크아웃

```
[대상] 총 채무 15억원 이하, 연체 3개월 미만
[신청] 신용회복위원회
[효과]
- 이자 감면 (최대 전액)
- 원금 감면 (최대 70%, 채무 규모별 차등)
- 상환 기간 최대 10년
[조건] 최저 생계비를 제외한 가용 소득으로 성실 상환
```

#### 개인회생

```
[대상] 급여소득자: 무담보 10억, 담보 15억 이하
       영업소득자: 무담보 10억, 담보 15억 이하
[신청] 관할 지방법원
[효과]
- 채무의 상당 부분 탕감 (원금의 5~30%만 상환)
- 3~5년 변제 계획에 따라 상환
- 변제 완료 시 잔여 채무 면책
[조건]
- 안정적 소득 필요 (상환 능력 입증)
- 법원 인가 변제 계획 엄격 준수
- 신용 회복에 5~7년 소요
```

#### 개인파산/면책

```
[대상] 지급 불능 상태 (채무 상환이 절대적으로 불가능)
[신청] 관할 지방법원
[효과]
- 재산 처분 후 잔여 채무 전액 면책
- 즉시 채무에서 해방
[조건]
- 파산 선고 + 면책 결정 필요
- 재산 처분 (생활 필수품 제외)
- 일부 직업 제한 (파산 기간 중)
- 신용 회복에 7~10년 소요
[주의] 최후의 수단으로만 고려
```

### 5.3 채무조정 선택 가이드

```
[상환 가능성 판단]

상환 가능 (일시적 어려움)
  → 프리워크아웃 또는 개인워크아웃

상환 일부 가능 (소득은 있으나 부족)
  → 개인회생

상환 불가능 (소득 없음 또는 극히 적음)
  → 개인파산/면책

[판단 기준]
가용 소득 = 월 소득 - 최저 생계비 - 필수 지출

가용 소득 > 총 채무의 월 최소 상환액 → 워크아웃
가용 소득으로 5년 내 일부 상환 가능 → 개인회생
가용 소득 거의 없음 → 개인파산
```

## 6. 좋은 부채 vs 나쁜 부채 상세

### 6.1 판단 기준

| 기준 | 좋은 부채 | 나쁜 부채 |
|------|----------|----------|
| 목적 | 자산 취득, 소득 창출 | 소비, 사치 |
| 금리 | 저금리 (5% 이하) | 고금리 (10% 이상) |
| 담보 | 담보 대출 (자산 연동) | 무담보 (신용 대출) |
| 세제 | 이자 공제 가능 | 공제 불가 |
| 자산 효과 | 자산 가치 상승 기대 | 자산 가치 하락/소멸 |

### 6.2 부채 유형별 분류

| 부채 유형 | 분류 | 이유 |
|-----------|------|------|
| 실거주 주담대 | 좋은 부채 | 주거 안정 + 자산 |
| 투자용 주담대 | 중립~주의 | 수익률에 따라 변동 |
| 전세대출 | 좋은 부채 | 주거비 절감 효과 |
| 사업자금 대출 | 좋은~중립 | 사업 성패에 따라 |
| 학자금 대출 | 좋은 부채 | 인적 자본 투자 |
| 자동차 할부 | 나쁜 부채 | 감가상각 자산 |
| 신용대출 (생활비) | 나쁜 부채 | 소비 목적 |
| 카드론/현금서비스 | 매우 나쁜 부채 | 초고금리 + 소비 |
| 리볼빙 | 매우 나쁜 부채 | 복리 이자 폭증 |

### 6.3 부채 활용 원칙

```
[원칙 1] 좋은 부채도 과도하면 나쁜 부채가 된다
  → DSR 40% 이하 유지

[원칙 2] 나쁜 부채는 즉시 상환한다
  → 고금리 소비성 대출 최우선 상환

[원칙 3] 레버리지는 감당 가능한 수준에서
  → 금리 상승, 소득 감소 시나리오 대비

[원칙 4] 부채 사용 전 질문한다
  → "이 대출로 취득하는 것이 이자보다 큰 가치를 만드는가?"

[원칙 5] 비상 상환 계획을 갖는다
  → 소득 중단 시 6개월간 상환 가능한 비상자금 확보
```
