# financial-debt-management

가족 재무 상담을 위한 부채 관리 및 대출 전략 가이드.

## 주요 기능

- 부채 상황 분석 및 상환 전략 수립
- DSR(채무상환비율) 및 DTI 관리
- 신용점수 개선 방법 제시
- 금리 최적화 및 대출 상품 비교
- 모기지 및 전세대출 전략 가이드
- 부채 리구조링 상담

## 사용 방법

- 에이전트 전용 스킬 (자동 위임)
- 트리거: 부채, 대출, 상환, DSR, DTI, 신용점수, 금리, 모기지, 전세대출
