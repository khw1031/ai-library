# financial-knowledge-manager

재무 지식 스킬에 데이터를 추가/수정/관리합니다.

## 주요 기능

- 재무 관련 정보 및 데이터 추가
- 기존 지식 데이터 수정 및 업데이트
- 참고자료 및 자료 관리
- 재무 정보 갱신 및 유지보수
- 스킬 데이터베이스 관리

## 사용 방법

- 호출: `/financial-knowledge-manager`
- 인자: [추가/수정할 정보 설명]
