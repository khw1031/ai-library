# learning-log-generator

Git 커밋 히스토리 기반으로 일자별 학습 로그를 생성합니다.

## 주요 기능

- Git 커밋 히스토리 기반 학습 로그 자동 생성
- 기간별 필터링 (오늘, 이번주, 최근 N일)
- 일자별 학습 내용 정리
- 학습 진도 추적

## 사용 방법

- 호출: `/learning-log-generator`
- 트리거: 학습 로그, 학습 기록, 일지 생성, recap, 복습 일정, 학습 요약
- 인자: [기간 - 예: 오늘, 이번주, 최근 7일]
