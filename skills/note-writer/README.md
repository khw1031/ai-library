# note-writer

Obsidian 호환 학습 노트를 Skill 형식으로 작성합니다. 텍스트, URL, 이미지, 영상 등 다양한 입력 지원.

## 주요 기능

- 다양한 입력 형식 지원 (텍스트, URL, 이미지, 영상)
- Obsidian 호환 마크다운 형식
- 태그 및 메타데이터 자동 추가
- 지식 정리 및 참고자료 관리

## 사용 방법

- 호출: `/note-writer`
- 트리거: 레퍼런스, 키워드, 개념 정리, 노트 작성, 지식 정리
- 인자: [컨텐츠 - 텍스트/URL/파일 등]

## 디렉토리 구조

```
note-writer/

```
