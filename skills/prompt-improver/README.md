# prompt-improver

프롬프트를 실증 기반 기법으로 분석하고 개선합니다. Few-shot, CoT, XML 구조화, Context Engineering 등 검증된 기법을 적용하여 프롬프트 품질을 높입니다.

## 주요 기능

- 실증 기반 프롬프트 분석
- Few-shot 학습 패턴 적용
- 체인 오브 생각(CoT) 기법 활용
- XML 구조화 및 컨텍스트 엔지니어링
- 프롬프트 품질 개선안 제시

## 사용 방법

- 호출: `/prompt-improver`
- 트리거: 프롬프트 개선, prompt 리뷰, 프롬프트 최적화, 프롬프팅 개선
- 인자: [프롬프트 텍스트 또는 파일 경로]
