# 은퇴 준비 상세 가이드

> 3층 연금 체계, 은퇴 자금 산출, 인출 전략, 연령대별 체크리스트 상세 정보

---

## 은퇴 필요 자금 산출 프레임워크

### 기본 산출 공식

```
은퇴 필요 자금 = (월 필요생활비 × 12 × 은퇴 후 기간) - (연금 예상 수령 총액)
```

### 상세 산출 단계

**1단계: 월 필요생활비 산정**

| 항목 | 부부 기준 월 예상 (2024) | 비고 |
|------|------------------------|------|
| 기본 생활비 (식비, 주거, 공과금) | 120~180만원 | 주거 형태에 따라 차이 |
| 의료/건강 | 30~60만원 | 연령 증가에 따라 상승 |
| 여가/문화 | 30~50만원 | 삶의 질 유지 |
| 교통/통신 | 15~25만원 | |
| 경조사/기타 | 20~40만원 | |
| **합계** | **215~355만원** | 개인차 큼 |

- 은퇴 직전 생활비의 약 70~80%를 기준으로 산정하는 것이 일반적
- 물가상승률 연 2.5% 반영 시 20년 후 현재 250만원 → 약 410만원

**2단계: 은퇴 후 기간 설정**

| 은퇴 연령 | 기대수명 (보수적) | 은퇴 후 기간 |
|----------|-----------------|-------------|
| 55세 | 90세 | 35년 |
| 60세 | 90세 | 30년 |
| 65세 | 90세 | 25년 |

- 보수적으로 기대수명을 90세로 설정 권장
- 부부 중 기대수명이 긴 쪽 기준으로 산정

**3단계: 연금 수령액 차감**

- 국민연금 예상 수령액: [국민연금공단](https://www.nps.or.kr) 내연금 알아보기 활용
- 퇴직연금 예상액: 현재 적립금 + 향후 납입 예상 + 운용수익
- 개인연금 예상액: 현재 잔액 + 향후 납입 + 운용수익

**4단계: 부족분 산정 및 대책 수립**

```
예시) 60세 은퇴, 부부 월 300만원 필요, 30년 기준
필요 총액: 300만 × 12 × 30 = 10억 8,000만원
국민연금 (부부): 월 150만 × 12 × 25(65세~) = 4억 5,000만원
퇴직연금: 2억원 (가정)
부족분: 약 4억 3,000만원 → 개인 준비 필요
(물가상승 미반영 단순 계산, 실제는 더 필요)
```

## 1층: 국민연금

### 핵심 제도 개요

| 항목 | 내용 |
|------|------|
| 가입 대상 | 18~59세 국내 거주 국민 |
| 보험료율 | 소득의 9% (근로자 4.5% + 사업주 4.5%) |
| 수급 개시 | 1969년 이후 출생: 65세 |
| 최소 가입기간 | 10년 (120개월) |
| 소득대체율 | 2028년까지 매년 0.5%씩 감소, 최종 40% 목표 |

### 국민연금 수령액 계산 요소

```
기본연금액 = A값 × (1 + 0.05 × 가입월수/12) × P값
A값: 전체 가입자 평균소득월액
P값: 개인의 가입기간 중 평균소득월액
```

- 가입기간이 길수록 수령액 증가
- 소득이 높을수록 수령액 증가하지만, 소득재분배 기능으로 저소득자에게 유리

### 조기수령 vs 연기수령

| 구분 | 조기수령 (최대 5년 전) | 정상수령 | 연기수령 (최대 5년 후) |
|------|---------------------|---------|---------------------|
| 수령 시기 | 60~64세 (출생연도별) | 65세 | 66~70세 |
| 감액/증액 | 연 6% 감액 (최대 30%) | 기준액 100% | 연 7.2% 증액 (최대 36%) |
| 적합 상황 | 건강 우려, 소득 없음 | 일반적 | 다른 소득 있음, 건강 양호 |
| 손익분기점 | 약 76~77세 | 기준 | 약 77~78세 |

**조기수령 판단 기준:**
- 건강 상태가 좋지 않은 경우
- 당장 생활비가 필요한 경우
- 다른 자산이 거의 없는 경우

**연기수령 판단 기준:**
- 근로소득이나 사업소득이 있는 경우 (재직자 노령연금 감액 회피)
- 건강 상태가 양호한 경우
- 다른 자산으로 생활비 충당 가능한 경우

### 국민연금 수령액 높이는 전략

1. **가입기간 최대화**: 임의가입, 추후납부 활용
2. **연기수령 활용**: 소득 있으면 5년 연기로 36% 증액
3. **부부 모두 가입**: 각각 독립적 수급권 확보
4. **추납제도 활용**: 미납기간 소급 납부 가능
5. **임의계속가입**: 60세 이후에도 65세까지 가입 가능

## 2층: 퇴직연금

### DB형 (확정급여형)

| 항목 | 내용 |
|------|------|
| 급여 산정 | 퇴직 직전 3개월 평균임금 × 근속연수 |
| 운용 책임 | 회사 (적립금 운용) |
| 적합 대상 | 임금상승률이 높은 경우, 장기근속 예상 |
| 장점 | 예측 가능한 퇴직급여, 임금상승분 반영 |
| 단점 | 회사 도산 리스크, 운용 참여 불가 |

### DC형 (확정기여형)

| 항목 | 내용 |
|------|------|
| 급여 산정 | 납입원금 + 운용수익 |
| 회사 납입 | 연간 임금총액의 1/12 이상 |
| 운용 책임 | 근로자 직접 운용 |
| 적합 대상 | 직접 운용 의향, 이직 빈번, 임금상승률 낮음 |
| 장점 | 직접 운용, 이직 시 연속성 |
| 단점 | 운용 손실 가능성, 원리금보장 상품에 방치 위험 |

### IRP (개인형 퇴직연금)

| 항목 | 내용 |
|------|------|
| 가입 대상 | 소득 있는 모든 취업자 |
| 납입 한도 | 연 1,800만원 (연금저축 합산) |
| 세액공제 | 연금저축 포함 연 700만원 한도 (13.2~16.5%) |
| 핵심 용도 | 퇴직금 수령 통로 + 추가 납입으로 세액공제 |
| 주의사항 | 55세 전 중도인출 제한적 (무주택 주택구입 등 예외) |

### DB vs DC 전환 판단

**DB 유지가 유리한 경우:**
- 향후 임금상승률 > 금융시장 수익률 예상
- 승진/호봉 상승 예정
- 투자에 관심 없거나 자신 없음
- 정년까지 근무 가능성 높음

**DC 전환이 유리한 경우:**
- 임금상승률이 정체 또는 낮음
- 직접 투자 운용에 자신 있음
- 이직 가능성이 높음
- 연봉제로 임금인상 불확실

### 퇴직연금 운용 전략 (DC형/IRP)

| 연령대 | 권장 포트폴리오 | 상품 예시 |
|--------|---------------|----------|
| 20~30대 | 공격형 (주식 70~80%) | TDF2050, 국내외 주식형 펀드 |
| 40대 | 균형형 (주식 50~60%) | TDF2040, 혼합형 펀드 |
| 50대 | 안정형 (주식 30~40%) | TDF2030, 채권혼합형 |
| 55세 이후 | 보수형 (주식 10~20%) | TDF2025, 예금/채권 중심 |

**TDF (Target Date Fund) 활용:**
- 은퇴 목표 연도에 맞춰 자동으로 자산배분 조정
- 초기에는 주식 비중 높고, 은퇴 시점 가까워지면 자동으로 보수적 전환
- 퇴직연금 내 기본값(default) 상품으로 적합

## 3층: 개인연금

### 연금저축 (연금저축펀드/연금저축보험)

| 항목 | 연금저축펀드 | 연금저축보험 |
|------|------------|------------|
| 가입처 | 증권사 | 보험사 |
| 운용 방식 | 펀드/ETF 직접 선택 | 보험사 공시이율 |
| 수수료 | 낮음 (ETF 0.1~0.5%) | 높음 (사업비 7~15%) |
| 원금 보장 | 없음 (운용 성과에 따라) | 있음 (최저보증이율) |
| 적합 대상 | 직접 운용 선호, 장기 수익 추구 | 원금 보장 우선 |
| 권장 | 대부분의 경우 연금저축펀드 권장 | |

**세액공제 요약:**

| 총급여 | 세액공제율 | 연금저축 한도 | IRP 포함 합산 한도 | 최대 공제액 |
|--------|----------|-------------|------------------|-----------|
| 5,500만원 이하 | 16.5% | 400만원 (600만원*) | 700만원 (900만원*) | 115.5만원 (148.5만원*) |
| 5,500만원 초과 | 13.2% | 400만원 (600만원*) | 700만원 (900만원*) | 92.4만원 (118.8만원*) |

(*50세 이상 우대한도, 2023년 세법 개정으로 전 연령 600/900만원 적용 추진 확인 필요)

### 연금 수령 시 세금

| 수령 방식 | 세율 | 비고 |
|----------|------|------|
| 연금 수령 (연 1,200만원 이하) | 3.3~5.5% (연령별) | 70세 미만 5.5%, 70~79세 4.4%, 80세+ 3.3% |
| 연금 수령 (연 1,200만원 초과) | 종합과세 또는 16.5% 분리과세 선택 | 2023년 세법 개정 |
| 연금 외 수령 (중도해지) | 16.5% 기타소득세 | 세액공제 받은 금액 + 운용수익 |

## 은퇴 후 인출 전략

### 4% 룰 (Four Percent Rule)

| 항목 | 내용 |
|------|------|
| 핵심 개념 | 은퇴 첫해에 자산의 4%를 인출, 이후 매년 물가상승률만큼 인출액 증가 |
| 근거 | 미국 주식/채권 역사적 수익률 기반 (트리니티 연구) |
| 성공 확률 | 30년간 자산 고갈 안 될 확률 약 95% (미국 기준) |
| 한국 적용 | 보수적으로 3~3.5%로 조정 권장 |
| 예시 | 총 자산 5억 → 첫해 인출 1,500~2,000만원 (월 125~167만원) |

**한국에서의 조정 요인:**
- 한국 시장 역사가 짧고 변동성이 더 큼
- 의료비 부담이 다를 수 있음
- 보수적으로 3~3.5% 적용 권장

### 버킷 전략 (Bucket Strategy)

자산을 시간대별로 3개 버킷으로 분류하여 관리:

| 버킷 | 기간 | 자산 유형 | 비중 | 목적 |
|------|------|----------|------|------|
| 1번 (단기) | 1~3년 | 예금, CMA, MMF | 15~20% | 당장의 생활비 |
| 2번 (중기) | 4~7년 | 채권, 채권형 펀드 | 30~40% | 1번 버킷 보충 |
| 3번 (장기) | 8년+ | 주식, 주식형 펀드 | 40~50% | 장기 성장, 인플레이션 대응 |

**운영 방법:**
1. 매월 1번 버킷에서 생활비 인출
2. 주기적으로(연 1~2회) 2번 → 1번, 3번 → 2번으로 보충
3. 주식시장 하락기에는 1~2번 버킷으로 버티고, 3번 버킷 매도 자제
4. 주식시장 상승기에 3번 버킷 일부를 1~2번으로 이동

**장점:**
- 시장 하락기에 주식 매도 강요 없음 (순서 리스크 방지)
- 심리적 안정감 (단기 자금이 확보되어 있음)
- 장기 자산의 성장 기회 유지

### 정률 인출 vs 정액 인출

| 방식 | 설명 | 장점 | 단점 |
|------|------|------|------|
| 정률 인출 | 매년 자산의 일정 비율 인출 (예: 4%) | 자산 고갈 방지 | 인출액 변동 큼 |
| 정액 인출 | 매년 동일 금액 인출 (물가 조정) | 생활비 예측 용이 | 자산 고갈 위험 |
| 하이브리드 | 정률 기반 + 최소/최대 인출액 설정 | 양쪽 장점 결합 | 관리 복잡 |

## 연령대별 은퇴 준비 체크리스트

### 30대: 기반 다지기

- [ ] 국민연금 가입 상태 확인 및 납부 이력 점검
- [ ] 퇴직연금 유형(DB/DC) 확인 및 적합성 검토
- [ ] 연금저축 계좌 개설 (연금저축펀드 권장)
- [ ] 세액공제 한도까지 납입 시작 (연 400만원+)
- [ ] 은퇴 목표 금액 대략적 산출
- [ ] TDF 등 장기 투자 상품으로 공격적 운용

### 40대: 본격 가속

- [ ] 은퇴 필요 자금 구체적 산출 (국민연금 예상액 확인)
- [ ] 연금저축 + IRP 세액공제 한도 최대 활용 (700만원)
- [ ] 퇴직연금 운용 상태 점검 (원리금보장 → 실적배당 전환 검토)
- [ ] 불필요한 보험 정리, 필요 보장 보완
- [ ] 자녀 교육비와 은퇴 자금 균형 점검
- [ ] 부채(주택담보대출 등) 상환 계획 수립

### 50대: 마무리 정비

- [ ] 국민연금 예상 수령액 정밀 확인 (NPS 홈페이지)
- [ ] 퇴직금 예상액 확인 및 수령 방식 결정 (일시금 vs 연금)
- [ ] 연금저축/IRP 자산배분을 안정형으로 전환
- [ ] 은퇴 후 주거 계획 수립 (다운사이징 검토)
- [ ] 건강보험 노후 대비 (실손보험 유지, 간병보험 검토)
- [ ] 부채 완전 상환 목표
- [ ] 은퇴 후 파트타임/재취업 가능성 검토

### 60대: 실행 단계

- [ ] 국민연금 수령 개시 (연기수령 여부 최종 결정)
- [ ] 퇴직금 IRP로 이체 → 연금 수령 개시
- [ ] 인출 전략 확정 (버킷 전략 또는 4% 룰)
- [ ] 월 현금흐름 점검 (연금 + 인출 = 생활비 충족?)
- [ ] 의료비 대비 (노후 의료비 평균 1억원+ 예상)
- [ ] 상속/증여 계획 수립 시작
- [ ] 후견인 지정, 유언장 작성 검토

## 은퇴 준비 핵심 체크포인트

### 40세에 점검해야 할 숫자

| 항목 | 최소 목표 | 양호 | 우수 |
|------|----------|------|------|

## 자주 묻는 질문

### Q: 국민연금이 고갈된다는데, 받을 수 있나요?
- 기금 고갈이 되더라도 부과 방식으로 전환하여 지급 가능
- 다만 급여 수준 조정(감액) 가능성은 있음
- 보수적 설계 시 예상 수령액의 70~80%로 계획 권장

### Q: 연금저축 vs IRP, 어디에 먼저 넣어야 하나요?
- 1순위: 연금저축 (중도인출 상대적 자유, 운용 자유도)
- 2순위: IRP (추가 세액공제 300만원 확보)
- 합산 700만원까지 채운 후 ISA 활용

### Q: 퇴직금을 일시금으로 받는 게 나을까요?
- 대부분의 경우 IRP로 이체 후 연금 수령이 유리
- 연금 수령 시 퇴직소득세 30~40% 감면
- 일시금이 유리한 경우: 부채 상환, 사업 자금 등 긴급한 대규모 자금 필요 시
