# 주요 지출 상세 가이드

> 주택 마련, 교육비, 결혼 자금, 비상금, 생애주기별 지출 타임라인 상세 정보

---

## 주택 마련

### 주택청약종합저축

| 항목 | 내용 |
|------|------|
| 가입 대상 | 대한민국 국민 누구나 (1인 1계좌) |
| 납입 한도 | 월 2만~50만원 |
| 청약 가점 | 가입기간 최대 17점 (15년 이상) |
| 금리 | 연 2.0~2.8% (가입기간별 차등) |
| 소득공제 | 무주택 세대주, 총급여 7,000만원 이하 시 납입액 40% (최대 240만원 한도) |

**청약 가점 체계 (총 84점):**

| 항목 | 배점 | 만점 기준 |
|------|------|----------|
| 무주택기간 | 32점 | 15년 이상 |
| 부양가족 수 | 35점 | 6명 이상 |
| 입주자저축 가입기간 | 17점 | 15년 이상 |

**청약 전략:**
1. 가능한 빨리 가입 (만 19세부터, 미성년자도 가입 가능하나 인정기간 제한)
2. 무주택기간 산정: 만 30세부터 or 결혼 시점부터 기산
3. 부양가족: 배우자, 직계존속(3년 이상 동거), 직계비속 포함
4. 월 납입액은 최소 10만원 이상 권장 (인정 회차 충족)

### 내집마련 로드맵

**단계별 전략:**

```
1단계: 종잣돈 마련 (2~5년)
├── 주택청약 가입 및 납입
├── 목표 주택 가격의 30~40% 자기자본 마련
└── 신용관리 (대출 심사 대비)

2단계: 주택 탐색 및 의사결정
├── 지역/면적/가격대 결정
├── 매매 vs 전세 vs 월세 비교분석
├── 정부 지원 대출 자격 확인
└── 청약 당첨 가능성 분석

3단계: 자금 조달
├── 자기자본 + 대출 비율 설정
├── 정부 지원 대출 우선 검토
├── 주택담보대출 금리/조건 비교
└── DTI/DSR 한도 확인

4단계: 매입 실행
├── 계약금 (보통 10%) → 중도금 → 잔금
├── 취득세, 중개수수료 등 부대비용 확보
└── 이사/인테리어 비용 예산
```

### 정부 지원 주택 대출

| 대출 상품 | 대상 | 금리 (2024 기준) | 한도 | 핵심 조건 |
|----------|------|-----------------|------|----------|
| 디딤돌대출 | 무주택 서민 | 연 2.15~3.0% | 최대 2.6억 | 부부합산 연소득 6,000만원 이하 |
| 보금자리론 | 무주택자/1주택자 | 연 3.5~4.5% | 최대 3.6억 | 부부합산 연소득 7,000만원 이하 |
| 신생아특례대출 | 출산가구 | 연 1.6~3.3% | 최대 5억 | 2년 내 출산, 소득 1.3억 이하 |
| 버팀목전세대출 | 무주택 세대주 | 연 1.8~2.4% | 수도권 1.2억 | 연소득 5,000만원 이하 |

*금리와 조건은 정책 변경에 따라 수시 변동, 최신 정보 확인 필요*

### 매매 vs 전세 의사결정 프레임워크

| 판단 기준 | 매매 유리 | 전세 유리 |
|----------|----------|----------|
| 거주 기간 | 5년 이상 장기 | 3년 이하 단기 |
| 주택 시장 전망 | 상승 또는 안정 | 하락 예상 |
| 대출 부담 | 감당 가능 (DSR 30% 이내) | 대출 부담 과중 |
| 자금 활용 | 주거 안정 우선 | 투자 수익 > 주거비 |
| 이동 가능성 | 낮음 (직장/학교 안정) | 높음 (전직/이사 가능) |
| 세금 | 1세대 1주택 비과세 활용 | 취득세/재산세 부담 없음 |

**전세자금 운용 팁:**
- 전세보증보험 가입 필수 (HUG, SGI)
- 전입신고 + 확정일자 당일 완료
- 전세가율(매매가 대비 전세가 비율) 70% 이하 선호
- 깡통전세 주의: 근저당 + 전세보증금 > 매매가 위험

### 주택 매입 시 부대비용 체크리스트

| 항목 | 비용 수준 | 비고 |
|------|----------|------|
| 취득세 | 매매가의 1~3% | 6억 이하 1%, 9억 초과 3% |
| 중개수수료 | 0.3~0.7% | 거래금액별 상한 |
| 법무사 비용 | 30~60만원 | 등기 대행 |
| 이사 비용 | 30~100만원 | 거리/짐량 |
| 인테리어/수리 | 변동 | 최소 500만원 예산 |
| 대출 부대비용 | 50~200만원 | 감정평가, 인지세 등 |

## 교육비 계획

### 단계별 교육비 상세

#### 유아기 (0~5세)

| 항목 | 월 비용 | 연 비용 | 정부 지원 |
|------|--------|--------|----------|
| 어린이집 | 0~50만원 | 0~600만원 | 보육료 지원 (0~2세 전액, 3~5세 누리과정) |
| 유치원 (사립) | 20~50만원 | 240~600만원 | 누리과정 지원금 |
| 기타 교육 (체능) | 10~30만원 | 120~360만원 | |

**절감 전략:**
- 국공립 어린이집/유치원 활용 (대기가 길지만 비용 절감 큼)
- 정부 보육료/유아교육비 지원 최대 활용
- 육아휴직 급여 활용 (통상임금 80%, 상한 월 150만원)

#### 초등학교 (7~12세)

| 항목 | 월 비용 | 연 비용 | 비고 |
|------|--------|--------|------|
| 학교 관련 | 5~10만원 | 60~120만원 | 급식비, 교재비 등 |
| 사교육 | 30~80만원 | 360~960만원 | 학원, 과외 |
| 방과후학교 | 5~15만원 | 60~180만원 | 학교 내 프로그램 |
| 돌봄교실 | 무료~5만원 | | 맞벌이 가정 |

**절감 전략:**
- 방과후학교 프로그램 적극 활용 (저렴하고 질 높음)
- 사교육비 월 상한선 설정 (가계 소득의 10% 이내 권장)
- EBS, 공공 교육 콘텐츠 활용

#### 중학교 (13~15세)

| 항목 | 월 비용 | 연 비용 | 비고 |
|------|--------|--------|------|
| 학교 관련 | 5~15만원 | 60~180만원 | 의무교육이나 부대비용 |
| 사교육 | 40~100만원 | 480~1,200만원 | 주요 과목 학원 |
| 자기주도학습 | 10~20만원 | 120~240만원 | 인강, 교재 |

| 항목 | 월 비용 | 연 비용 | 비고 |

| 사교육 | 50~150만원 | 600~1,800만원 | 대입 집중 시기 |
| 수능/대입 비용 | | 100~300만원 | 수능, 수시 원서, 면접 등 |

| 항목 | 학기 비용 | 연 비용 | 비고 |

### 교육비 마련 전략

| 전략 | 설명 | 적합 시기 |
|------|------|----------|
| 자녀 명의 적금 | 매월 정기 납입, 증여세 비과세 한도 활용 | 출생~초등 |
| 교육비 전용 투자 | 자녀 교육 목표 펀드 (TDF 유사) | 출생~중학 |
| 학자금 대출 활용 | 한국장학재단 학자금 대출 | 대학 진학 시 |
| 장학금 준비 | 성적/소득 기반 장학금 탐색 | 고등~대학 |

**자녀 증여 비과세 한도:**
- 미성년자: 10년간 2,000만원
- 성년자: 10년간 5,000만원
- 출생 시부터 계획적 증여로 합법적 자산 이전

### 교육비 vs 은퇴자금 균형

**핵심 원칙: 은퇴 자금에는 대출이 없지만, 교육에는 학자금 대출이 있다.**

| 상황 | 권장 우선순위 |
|------|-------------|
| 은퇴까지 20년+ | 교육비와 은퇴 자금 병행 (비율 조정) |
| 은퇴까지 10~20년 | 은퇴 자금 60% : 교육비 40% |
| 은퇴까지 10년 이내 | 은퇴 자금 최우선, 교육비는 학자금 대출 활용 |

## 결혼 자금 준비

### 결혼 비용 상세 항목

| 카테고리 | 항목 | 예상 비용 | 비고 |
|----------|------|----------|------|
| **예식** | 웨딩홀 | 300~800만원 | 지역/시즌/요일별 차이 |
| | 드레스/턱시도 | 100~400만원 | 렌탈 vs 구매 |
| | 메이크업/사진/영상 | 200~500만원 | 패키지 활용 |
| | 청첩장/답례품 | 30~80만원 | |
| | 예물(반지 등) | 100~500만원 | |
| | **예식 소계** | **730~2,280만원** | |
| **신혼집** | 전세/매매 자금 | 1억~5억+ | 최대 비중 항목 |
| | 인테리어/수리 | 300~1,500만원 | 범위 매우 넓음 |
| **혼수** | 가전제품 | 300~800만원 | 혼수가전 패키지 |
| | 가구 | 200~600만원 | |
| | 생활용품 | 50~150만원 | |
| | **혼수 소계** | **550~1,550만원** | |
| **허니문** | 여행 | 200~600만원 | 국내/해외/기간별 |

### 결혼 자금 마련 전략

**3단계 접근:**

```
1단계: 목표 설정 (결혼 2~3년 전)
├── 총 필요 예산 산정
├── 양가 지원 예상액 파악
├── 본인 부담 금액 확정
└── 월 저축 계획 수립

2단계: 자금 축적 (결혼 1~2년 전)
├── 전용 계좌 개설 (적금/CMA)
├── 월 고정 저축 자동이체
├── 보너스/성과급 전액 투입
└── 지출 절감 집중 기간 운영

3단계: 자금 집행 (결혼 6개월~당일)
├── 우선순위별 지출 (주거 > 예식 > 혼수)
├── 축의금 수입 반영
├── 비상 여유자금 10% 확보
└── 신혼 초기 생활비 별도 확보
```

**비용 절감 포인트:**
- 예식: 비수기/평일 예식 (30~50% 할인), 스몰웨딩
- 혼수: 필수품 위주 단계적 구매, 렌탈 활용
- 허니문: 비수기 여행, 마일리지 활용
- 축의금으로 예식비의 70~100% 상쇄 가능 (하객 수에 따라)

## 비상자금 (긴급 자금)

### 적정 규모 가이드라인

| 가구 상황 | 최소 | 권장 | 비고 |
|----------|------|------|------|
| 맞벌이, 안정 직장 | 월 생활비 3개월 | 6개월 | 실직 리스크 낮음 |
| 외벌이, 안정 직장 | 월 생활비 6개월 | 9개월 | 소득원 단일 |
| 자영업/프리랜서 | 월 생활비 6개월 | 12개월 | 소득 변동성 큼 |
| 은퇴자/고령자 | 월 생활비 12개월 | 24개월 | 재취업 어려움 |

### 비상자금 운용 방법

| 우선순위 | 금액 | 보관 방법 | 이유 |
|---------|------|----------|------|
| 1차 | 월 생활비 1개월 | 입출금통장/CMA | 즉시 인출 가능 |
| 2차 | 월 생활비 2~3개월 | 파킹통장/MMF | 하루 이내 인출, 약간의 이자 |
| 3차 | 월 생활비 3~6개월 | 단기 정기예금 | 1~3개월 만기, 중도해지 가능 |

**비상자금 사용 기준 (이것만 해당):**
- 실직/소득 중단
- 긴급 의료비 (보험 미보장분)
- 주거 관련 긴급 수리
- 가족 긴급 상황

**비상자금에 해당하지 않는 것:**
- 여행, 가전 교체 → 별도 목표 저축
- 투자 기회 → 투자는 투자자금으로
- 세일/할인 기회 → 소비 유혹 차단

## 생애주기별 주요 지출 타임라인

### 연령대별 예상 대규모 지출

```
25세 ──── 자동차 (2,000~4,000만원)
  │
28세 ──── 결혼 (3,000~8,000만원, 주거 별도)
  │
30세 ──── 주택마련 (2~6억원, 대출 포함)
  │
31세 ──── 출산/육아 시작 (연 500~1,000만원)
  │
35~48세 ── 자녀 교육비 (연 500~2,000만원 × 자녀 수)
  │
45세 ──── 부모 부양 시작 가능성 (연 500~1,500만원)
  │
48세 ──── 자녀 대학 (연 1,000~2,000만원 × 4년)
  │
52세 ──── 주택 리모델링 (2,000~5,000만원)
  │
55세 ──── 자녀 결혼 지원 (3,000~1억원)
  │
60세 ──── 은퇴 시작
  │
60~90세 ── 의료비 누적 (총 1~2억원 예상)
```

### 재무 이벤트 대비 사전 준비 기간

| 이벤트 | 필요 준비 기간 | 핵심 행동 |
|--------|--------------|----------|
| 결혼 | 2~3년 전 | 목표액 설정, 월 저축 시작 |
| 주택 매입 | 3~5년 전 | 청약, 종잣돈 마련, 신용관리 |
| 자녀 대학 | 18년 전 (출생 시) | 교육비 투자 시작, 장기 적립 |
| 은퇴 | 20~30년 전 | 연금 가입, 세액공제 활용 시작 |
| 부모 부양 | 5~10년 전 | 부모 재무 상태 파악, 비용 추정 |

## 생애재무설계 연간 점검표

매년 1회 (생일 또는 연초) 점검 권장:

- [ ] 순자산(자산-부채) 계산 및 전년 대비 변화 확인
- [ ] 연금 자산 현황 점검 (국민연금 + 퇴직연금 + 개인연금)
- [ ] 보험 보장 내역 검토 (과잉/부족 점검)
- [ ] 향후 3년 내 대규모 지출 이벤트 확인
- [ ] 비상자금 적정 규모 유지 여부 확인
- [ ] 부채 상환 진행률 점검
- [ ] 자산배분 리밸런싱 필요 여부 확인
- [ ] 세금 최적화 전략 점검 (절세상품 한도 활용)
