# first-principles

일론 머스크의 1원칙(First Principles Thinking) 기반으로 문제를 분석합니다.

## 주요 기능

- 4명의 전문가 관점에서 문제 해체 (Physicist, Socratic Philosopher, Systems Engineer, Domain Specialist)
- Phase 1: Assumption Excavation (현존 가정 5-7개 나열, 출처 분류: 관습/기술적 제약/물리 법칙/검증된 사실)
- Phase 2: Fundamental Decomposition (경고 대상 가정에 5 Whys 기법 적용, 근본 요소 추출)
- Phase 3: Ground-Up Reconstruction (근본 요소만으로 새 해결책 3개 이상 도출, 장단점 분석)
- 기존 접근법과 다른 해결 경로 제시
- 각 근본 원리의 근거/증거 제시
- "왜 기존에는 이렇게 하지 않았는가?"에 대한 가설 제시
- 구조화된 출력 (가정 해부 → First Principles 목록 → 재구성된 해결책 → 실행 권고)

## 사용 방법

- 호출: `/first-principles` (또는 트리거 키워드: 가정 해체, 근본 원리 추출, 해결책 재구성, 1원칙 사고, first principles)
- 인자: [분석할 문제/질문/주제]
