# document-consolidator

여러 문서를 통합하여 구조화된 단일 문서로 만듭니다.

## 주요 기능

- 여러 문서 내용을 분석하여 핵심 주제 파악
- 공통 테마 및 중복 내용 식별 및 병합
- 웹 검색으로 식별된 보강 필요 영역을 자동 보강
- 신뢰할 수 있는 출처 우선 수집 (공식 문서, 학술자료, 신뢰 매체)
- 논리적 섹션으로 구조화 및 계층적 구조 설계
- Executive Summary, 목차, 본문, References, 메타 정보를 포함한 통합 문서 생성
- 원본 출처와 웹 검색 출처 분리 명시

## 사용 방법

- 호출: `/document-consolidator` (또는 트리거 키워드: 문서 통합, 문서 병합, 자료 정리, 내용 합치기, consolidate)
- 인자: [문서1 내용] [문서2 내용] ...

## 디렉토리 구조

```
document-consolidator/
├── SKILL.md
└── references/
    ├── consolidation-strategy.md
    └── web-enrichment.md
```
