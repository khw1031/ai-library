# 금융상품 상세 가이드

> 가족 재무 상담 시 참고할 금융상품 유형별 상세 정보

---

## 1. 예금/적금

### 정기예금

| 항목 | 내용 |
|------|------|
| 구조 | 목돈을 일정 기간 예치, 만기 시 원금+이자 수령 |
| 금리 유형 | 고정금리 / 변동금리 |
| 가입 기간 | 1개월~36개월 (일반적으로 12개월) |
| 위험도 | 매우 낮음 (예금자보호 5,000만원) |
| 중도해지 | 가능하나 약정금리 대비 대폭 감소 |

**상담 포인트**:
- 예금자보호는 금융기관별 1인당 5,000만원 (원금+이자 합산)
- 금리 비교 시 세전/세후 금리 구분 필수
- 특판 예금은 조건(급여이체, 카드실적 등) 확인
- 금리 상승기에는 단기 예금, 하락기에는 장기 예금 유리

### 정기적금

| 항목 | 내용 |
|------|------|
| 구조 | 매월 일정액 납입, 만기 시 원리금 수령 |
| 납입 금액 | 월 1만원~수백만원 (상품마다 상이) |
| 가입 기간 | 6개월~36개월 |
| 위험도 | 매우 낮음 (예금자보호 적용) |
| 실효 수익률 | 표시 금리의 약 55% 수준 (이자 계산 방식 차이) |

**상담 포인트**:
- 적금 금리는 예금 금리보다 높아 보이지만, 실제 수령액은 예금이 유리할 수 있음
- 적금의 장점은 강제 저축 효과
- 납입일 관리 중요 (자동이체 설정 권장)

### 자유적금

| 항목 | 내용 |
|------|------|
| 구조 | 납입 시기와 금액 자유, 한도 내 수시 납입 |
| 장점 | 비정기 소득자에 적합, 유동성 확보 |
| 단점 | 정기적금 대비 금리 낮은 경우 다수 |
| 위험도 | 매우 낮음 |

### CMA (Cash Management Account)

| 항목 | 내용 |
|------|------|
| 구조 | 증권사 수시입출금 계좌, 하루 단위 이자 |
| 유형 | RP형, 발행어음형, MMF형, 종금형 |
| 금리 | 시장금리 연동, 일반 예금 대비 높은 경우 많음 |
| 예금자보호 | 종금형만 적용, 나머지는 미적용 |
| 적합 대상 | 비상금, 단기 여유자금 관리 |

**유형별 비교**:

| CMA 유형 | 예금자보호 | 수익률 | 안정성 |
|----------|----------|--------|--------|
| RP형 | X | 중간 | 높음 (국채 담보) |
| 발행어음형 | X | 높음 | 증권사 신용 |
| MMF형 | X | 중간 | 높음 (분산투자) |
| 종금형 | O (5,000만원) | 낮음 | 최고 |

## 2. 채권

### 채권 기본 개념

| 항목 | 내용 |
|------|------|
| 정의 | 발행자가 투자자에게 원금 상환과 이자 지급을 약속하는 유가증권 |
| 수익 구조 | 이자 수익(쿠폰) + 매매 차익(시장가 변동) |
| 금리 관계 | 금리 상승 시 채권 가격 하락, 금리 하락 시 가격 상승 (역관계) |
| 만기 | 단기(1년 이내), 중기(1~5년), 장기(5년 초과) |

### 채권 유형별 상세

| 유형 | 발행 주체 | 신용위험 | 수익률 | 특징 |
|------|----------|---------|--------|------|
| 국채 | 정부 | 거의 없음 | 낮음 | 안전자산의 기준, 금리 벤치마크 |
| 지방채 | 지자체 | 매우 낮음 | 낮음~중간 | 지방정부 재정 기반 |
| 특수채 | 공공기관 | 낮음 | 중간 | 한전, 도공 등 |
| 회사채 | 기업 | 등급별 상이 | 중간~높음 | 신용등급 AAA~D |
| 전환사채(CB) | 기업 | 중간 | 중간 | 주식 전환 옵션 |

### 채권 신용등급

| 등급 | 의미 | 투자 적합성 |
|------|------|------------|
| AAA | 원리금 지급 확실 | 안전투자 |
| AA+~AA- | 매우 우수 | 안전투자 |
| A+~A- | 우수 | 적격투자 |
| BBB+~BBB- | 양호 (투자적격 최하) | 주의 필요 |
| BB+ 이하 | 투기등급 | 고위험 (비권장) |

**상담 포인트**:
- 개인투자자는 국채, AAA~AA급 회사채 위주 권장
- 채권형 펀드/ETF를 통한 간접투자가 접근성 높음
- 금리 전환기에는 듀레이션(잔존만기) 관리 중요
- 개인투자용 국채(만기보유 시 가산금리 + 분리과세) 활용 가능

## 3. 주식/펀드

### ETF (상장지수펀드)

| 항목 | 내용 |
|------|------|
| 정의 | 특정 지수를 추종하는 펀드를 주식처럼 거래 |
| 장점 | 분산투자, 저비용, 실시간 매매, 투명한 구성 |
| 비용 | 총보수 연 0.01~0.5% (인덱스형 기준) |
| 유형 | 국내지수, 해외지수, 섹터, 채권, 원자재, 레버리지/인버스 |

**주요 ETF 카테고리**:

| 카테고리 | 대표 지수 | 특징 |
|---------|----------|------|
| 국내 대형주 | KOSPI200, KRX300 | 한국 대표기업 분산 |
| 미국 대형주 | S&P500, NASDAQ100 | 글로벌 핵심 자산 |
| 글로벌 | MSCI World, ACWI | 전세계 분산 |
| 채권 | 국고채, 미국채 | 안전자산 편입 |
| 배당 | 고배당지수 | 인컴 수익 추구 |

**상담 포인트**:
- 초보 투자자에게 가장 권장되는 투자 수단
- 국내 상장 해외 ETF vs 해외 직접투자 ETF 세금 차이 확인
- 레버리지/인버스 ETF는 장기투자 부적합 (일별 수익률 추종)
- 괴리율, 거래량 확인 후 투자

### 인덱스펀드

| 항목 | 내용 |
|------|------|
| 정의 | 특정 시장지수 수익률을 그대로 복제하는 펀드 |
| ETF와 차이 | 실시간 매매 불가, 기준가 기준 매매 (1일 1회) |
| 장점 | 자동 적립식 매수 편리, 최소 투자금 낮음 |
| 비용 | 총보수 연 0.1~0.5% |

### 액티브펀드

| 항목 | 내용 |
|------|------|
| 정의 | 펀드매니저가 적극적으로 종목 선정하여 초과수익 추구 |
| 장점 | 시장 대비 초과수익 가능성 |
| 단점 | 높은 보수(연 1~2%), 장기적으로 인덱스 대비 저성과 비율 높음 |
| 선택 기준 | 3~5년 성과, 펀드매니저 경력, 운용 규모, 보수율 |

**상담 포인트**:
- 대부분의 액티브펀드가 장기적으로 인덱스를 하회 (SPIVA 데이터)
- 비용 차이가 장기 복리에 미치는 영향 설명 필요
- 액티브 선호 시 검증된 운용사의 장기 트랙레코드 확인

### 개별주식

| 항목 | 내용 |
|------|------|
| 장점 | 높은 수익 가능성, 직접 기업 분석/선택 |
| 단점 | 높은 변동성, 개별 기업 리스크, 시간/노력 필요 |
| 권장 비중 | 전체 투자자산의 10~20% 이내 (위성 자산) |

## 4. 절세 금융상품

### ISA (개인종합자산관리계좌)

| 구분 | 일반형 | 서민형 | 농어민형 |
|------|--------|--------|---------|
| 가입 조건 | 만 19세 이상 (근로소득 시 15세) | 총급여 5,000만원 이하 또는 종합소득 3,800만원 이하 | 농어민 |
| 납입한도 | 연 2,000만원 (총 1억원) | 동일 | 동일 |
| 의무가입 기간 | 3년 | 3년 | 3년 |
| 비과세 한도 | 200만원 | 400만원 | 400만원 |
| 초과분 과세 | 9.9% 분리과세 | 9.9% 분리과세 | 9.9% 분리과세 |

**ISA 유형**:

| 유형 | 운용 방식 | 적합 대상 |
|------|----------|----------|
| 중개형 | 투자자 직접 운용 (주식, ETF 등) | 직접투자 선호 |
| 신탁형 | 금융기관 위탁 운용 | 위탁 운용 선호 |
| 일임형 | 전문가 포트폴리오 운용 | 초보 투자자 |

**ISA 핵심 장점**:
- **손익통산**: 계좌 내 수익과 손실을 상계 후 세금 계산
- **다양한 상품 편입**: 국내주식, ETF, 펀드, 예금, ELS 등
- **만기 후 연금 전환**: 추가 세액공제 혜택 (전환금액의 10%, 최대 300만원)

**상담 포인트**:
- 3년 의무가입 기간 유의 (중도해지 시 세제혜택 소멸)
- 서민형 자격 확인 (매년 소득 기준 충족 여부)
- 국내주식 매매차익은 ISA 밖에서도 비과세이므로, ISA에는 배당주/해외ETF/채권 등 편입 유리
- 만기 도래 시 연금계좌 전환 적극 권장

### 연금저축

| 구분 | 연금저축펀드 | 연금저축보험 | 연금저축신탁 |
|------|------------|------------|------------|
| 판매 | 증권사 | 보험사 | 은행 (신규 중단) |
| 운용 | 펀드/ETF 직접 선택 | 공시이율 적용 | 신탁 운용 |
| 원금보장 | X | O (최저보증) | 일부 |
| 수수료 | 낮음 (0.1~0.5%) | 높음 (사업비 차감) | 중간 |
| 추천 대상 | 투자형 | 안정형 | (신규 불가) |

**세액공제 상세**:

| 구분 | 총급여 5,500만원 이하 | 총급여 5,500만원 초과 |
|------|---------------------|---------------------|
| 공제율 | 16.5% | 13.2% |
| 연금저축 한도 | 400만원 | 400만원 |
| IRP 포함 한도 | 700만원 | 700만원 |
| 최대 공제액 (연금저축만) | 66만원 | 52.8만원 |
| 최대 공제액 (IRP 포함) | 115.5만원 | 92.4만원 |

**수령 시 과세**:

| 연금 수령 나이 | 세율 |
|--------------|------|
| 70세 미만 | 5.5% |
| 70세~80세 미만 | 4.4% |
| 80세 이상 | 3.3% |

**상담 포인트**:
- 연금저축펀드가 장기 수익률 면에서 가장 유리 (비용 낮고 운용 자유)
- 55세 이후 연금 수령 시 저율 과세 (3.3~5.5%)
- 중도인출 시 기타소득세 16.5% 부과 (세액공제 받은 금액 + 운용수익)
- 세액공제 미적용분(400만원 초과 납입분)은 중도인출 시 비과세

### IRP (개인형퇴직연금)

| 항목 | 내용 |
|------|------|
| 납입한도 | 연 1,800만원 (연금저축 포함) |
| 세액공제 | 연금저축+IRP 합산 700만원 한도 |
| 운용 상품 | 예금, 펀드, ETF, 리츠 등 (위험자산 70% 한도) |
| 수령 시 | 연금소득세 3.3~5.5% |
| 중도인출 | 법정 사유만 가능 (무주택자 주택구입, 6개월 이상 요양 등) |
| 퇴직금 이체 | 가능 (퇴직금 수령 시 세제 혜택) |

**연금저축 vs IRP 비교**:

| 비교 항목 | 연금저축 | IRP |
|----------|---------|-----|
| 중도인출 | 자유 (과세) | 법정 사유만 |
| 위험자산 한도 | 제한 없음 | 70% 한도 |
| 퇴직금 이체 | 불가 | 가능 |
| 수수료 | 없음~낮음 | 계좌 운용 수수료 있을 수 있음 |
| 추가 공제 한도 | 400만원 | 300만원 추가 (합산 700만원) |

**상담 포인트**:
- 연금저축 400만원 + IRP 300만원 = 700만원 세액공제 극대화 전략
- IRP는 위험자산 70% 제한이 있어, 공격적 투자 시 연금저축 활용
- 퇴직 시 퇴직금을 IRP로 이체하면 퇴직소득세 이연(연금 수령 시 30~40% 감면)
- 55세 이전 해지 시 기타소득세 16.5% 부과

### 절세상품 활용 우선순위 (일반적 권장)

```
1순위: 연금저축 400만원 (세액공제 + 유동성)
    ↓
2순위: IRP 300만원 추가 (세액공제 극대화)
    ↓
3순위: ISA 한도 활용 (비과세 + 손익통산)
    ↓
4순위: 일반 계좌 투자 (절세 혜택 소진 후)
```

**소득 수준별 절세 효과 비교** (연금저축+IRP 700만원 납입 시):

| 총급여 | 공제율 | 연간 절세액 | 20년 누적 절세 |
|--------|-------|-----------|--------------|
| 5,500만원 이하 | 16.5% | 115.5만원 | 2,310만원 |
| 5,500만원 초과 | 13.2% | 92.4만원 | 1,848만원 |
