# musk-algorithm

Elon Musk의 5단계 문제 해결 알고리즘을 적용하여 문제를 분석합니다.

## 주요 기능

- 5단계 문제 해결 프레임워크 적용
- First Principles 사고 방식 활용
- 근본 원인 분석 및 해결책 도출
- 최적화 및 프로세스 개선 지원

## 사용 방법

- 호출: `/musk-algorithm`
- 트리거: 문제 해결, 최적화, 프로세스 개선, 효율화, 단순화, First Principles
- 인자: [해결할 문제 또는 개선할 대상]

## 디렉토리 구조

```
musk-algorithm/
├── SKILL.md
```
